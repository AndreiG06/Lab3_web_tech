## Ход работы

### 1. Условные конструкции

Сначала я создал файл `schedule.php`, в котором выводится таблица с графиком работы двух сотрудников. График зависит от текущего дня недели.

Чтобы узнать день недели, я использовал функцию `date('N')`. Она возвращает число от 1 до 7, где 1 — понедельник, а 7 — воскресенье. Это удобнее, чем `date('l')`, потому что с числами проще сравнивать, чем с английскими названиями дней.

Дальше с помощью `if/else` я проверяю, работает ли сотрудник сегодня:

```php
$today = date('N');

// John Styles работает в пн, ср, пт
if ($today == 1 || $today == 3 || $today == 5) {
    $john = '8:00-12:00';
} else {
    $john = 'Нерабочий день';
}

// Jane Doe работает во вт, чт, сб
if ($today == 2 || $today == 4 || $today == 6) {
    $jane = '12:00-16:00';
} else {
    $jane = 'Нерабочий день';
}
```

Полученные значения подставляются в HTML-таблицу через `<?= $john ?>` и `<?= $jane ?>`. Над таблицей я также вывел название текущего дня на русском языке. Для этого я сделал массив `$dayNames`, где ключ — номер дня, а значение — его название.

Пример результата для понедельника:

| №  | Фамилия Имя  | График работы  |
|----|--------------|----------------|
| 1  | John Styles  | 8:00-12:00     |
| 2  | Jane Doe     | Нерабочий день |

В воскресенье у обоих сотрудников выводится «Нерабочий день», так как 7 не входит ни в одно из условий.

### 2. Циклы

Затем я создал файл `index.php` с кодом из задания:

```php
$a = 0;
$b = 0;

for ($i = 0; $i <= 5; $i++) {
    $a += 10;
    $b += 5;
}

echo "End of the loop: a = $a, b = $b";
```

По заданию нужно было выводить промежуточные значения `$a` и `$b` на каждом шаге, поэтому внутрь цикла я добавил строку:

```php
echo "Итерация $i: a = $a, b = $b<br>";
```

Результат работы цикла:

| Итерация | a  | b  |
|----------|----|----|
| 0        | 10 | 5  |
| 1        | 20 | 10 |
| 2        | 30 | 15 |
| 3        | 40 | 20 |
| 4        | 50 | 25 |
| 5        | 60 | 30 |

`End of the loop: a = 60, b = 30`

Цикл выполняется 6 раз, а не 5, потому что `$i` начинается с 0 и в условии стоит `<=`.

### 3. Переписывание цикла через `while` и `do-while`

Потом я переписал этот же цикл через `while`. В `while` нет отдельного места для счётчика, поэтому `$i = 0` я объявил перед циклом, а `$i++` перенёс в конец тела цикла:

```php
$i = 0;
while ($i <= 5) {
    $a += 10;
    $b += 5;
    echo "Итерация $i: a = $a, b = $b<br>";
    $i++;
}
```

Вариант с `do-while` отличается тем, что условие проверяется уже после выполнения тела:

```php
$i = 0;
do {
    $a += 10;
    $b += 5;
    echo "Итерация $i: a = $a, b = $b<br>";
    $i++;
} while ($i <= 5);
```

Перед каждым циклом я заново обнулял `$a` и `$b`, чтобы результаты не накапливались. Все три цикла выдали одинаковый результат: `a = 60, b = 30`. Чтобы результаты было легко различать на странице, я вывел каждый цикл в отдельном блоке с заголовком.

## Контрольные вопросы

**1. В чём разница между циклами `for`, `while` и `do-while`? В каких случаях лучше использовать каждый из них?**

- `for` — счётчик, условие и шаг пишутся в одной строке. Его лучше использовать, когда заранее известно, сколько раз нужно повторить действие. Например, как в этой работе: от 0 до 5.
- `while` — сначала проверяется условие, а потом выполняется тело. Если условие сразу ложное, тело не выполнится ни разу. Он подходит, когда количество повторений заранее неизвестно, например при чтении файла построчно, пока строки не закончатся.
- `do-while` — сначала выполняется тело, а потом проверяется условие, поэтому тело выполнится хотя бы один раз. Его удобно использовать, когда действие точно нужно сделать минимум один раз, например запросить ввод у пользователя и повторять, пока он не введёт правильное значение.

**2. Как работает тернарный оператор `? :` в PHP?**

Тернарный оператор — это сокращённая запись `if/else`, которая возвращает значение:

```
условие ? значение_если_true : значение_если_false
```

Например, проверку для John Styles можно записать в одну строку:

```php
$john = ($today == 1 || $today == 3 || $today == 5) ? '8:00-12:00' : 'Нерабочий день';
```

Если условие истинно, в переменную записывается первое значение, если ложно — второе. Ещё есть короткая форма `$x ?: 'значение'`: она вернёт `$x`, если он истинный, иначе — `'значение'`. Вкладывать тернарные операторы друг в друга лучше не стоит, потому что код становится трудно читать (а в PHP 8 вложенные тернарники без скобок вообще выдают ошибку).

**3. Что произойдёт, если в `do-while` поставить условие, которое изначально ложно?**

Тело цикла всё равно выполнится один раз, потому что в `do-while` условие проверяется после выполнения тела. После первой итерации условие окажется ложным, и цикл завершится.

```php
$i = 10;
do {
    echo $i; // выведется 10
} while ($i < 5);
```

Если бы это был обычный `while`, то ничего бы не вывелось.
